# IntelliMeet frontend

React + TypeScript (Vite), Tailwind, shadcn/ui, TanStack Query, React Router.

```bash
npm install
API_TARGET=http://localhost:8000 npm run dev   # proxies /api to the backend
npm test                                       # Vitest
npm run typecheck && npm run lint && npm run build
npm run gen:api                                # regenerate src/api/schema.d.ts from ../docs/openapi.json
```

- `src/api/`: typed client (types generated from the OpenAPI contract) and the SSE reader for `/api/chat`
- `src/pages/`: chat (`/`) and meeting detail (`/meetings/:id?turn=N`, highlights the cited line)
- `src/components/ui/`: generated by the shadcn CLI; avoid hand edits
